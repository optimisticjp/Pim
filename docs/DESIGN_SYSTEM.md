# Madhavanand Digital Design System

## Creative thesis

**શાંતિ + પરંપરા + જ્ઞાન + સેવા**

The visual idea is “quiet ashram editorial”: warm paper-like surfaces, deep temple maroon, restrained kesariya, a supporting sacred green, Gujarati serif typography, temple-arch geometry and thin manuscript-like rules. It should never look like a generic festival poster converted into a website.

## Signature element: Madhav Rekha

The four principles — ધર્મ, ભક્તિ, જ્ઞાન, વૈરાગ્ય — are treated as an actual structural system, not decorative labels. The `MadhavRekha` component gives the site a repeatable identity and can later evolve into timeline/navigation motifs.

## Colors

- `#FBF7EF` — Ashram Sand, primary canvas
- `#FFFDF8` — Sacred Paper, cards
- `#711F2D` — Temple Maroon, primary action/identity
- `#571621` — Deep Maroon, emphasis
- `#C7812B` — Kesariya Gold, accents only
- `#9A601F` — Antique Gold, small labels and rules
- `#294C45` — Sacred Green, seva/verification/supporting theme
- `#2E2520` — warm charcoal text

Kesari is intentionally limited. Maroon is the anchor; sand carries most of the interface.

## Typography

- Display/headings: Noto Serif Gujarati
- Body/navigation/UI: Noto Sans Gujarati

Gujarati needs more line-height than Latin interfaces. Long body copy should usually remain 17–18px on desktop and about 16.5–17px on mobile.

## Geometry

- Soft cards: 18–22px radius
- Sacred arch: very large upper radii, restrained lower radius
- Buttons: pills for global CTAs, 12–14px radius for functional admin buttons
- Lines/borders are warm, never cold grey

## Motion

Motion should be almost invisible: hover lift, small fades, one purposeful hero orchestration if added later. No rotating Om, particles, bouncing CTA, autoplay audio or animation that delays reading.

## Mobile strategy

The phone is the primary device. The sticky bottom navigation exposes five common intents:

1. મુખપૃષ્ઠ
2. કાર્યક્રમ
3. સત્સંગ
4. આશ્રમ
5. સંપર્ક

This specifically serves visitors arriving from WhatsApp who need one task quickly.

## Content UX

- Do not put essential event details only inside poster images.
- Phone is tap-to-call.
- Address goes directly to map directions.
- YouTube stays the canonical video host.
- PDFs can be read inline but also opened directly.
- Unverified branch details stay blank rather than receiving fabricated content.
- Donation information stays absent until formally approved.
